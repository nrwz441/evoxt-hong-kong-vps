## 常见问题

**香港 VPS 一定要备案吗？**
不需要。香港节点不在大陆 ICP 备案的管辖范围内，域名解析过去、服务起来就能访问，不用等审核。

**Evoxt 香港实际延迟多少？**
看地区和运营商。已有的公开测试数据里，上海移动方向 28–30ms，北京电信、联通、鹏博士方向 73–87ms。华南、华东用户体感会明显好于华北、东北用户。这些数字来自 2023 年的路由记录，实际会随线路调整变化，以你自己 ping 的结果为准。

**KVM 和 OpenVZ 有什么区别，Evoxt 是哪种？**
KVM 是完整硬件虚拟化，内核独立，能跑 Docker、WireGuard、自定义内核模块；OpenVZ 共享宿主内核，上面这些基本用不了。买任何一家的香港 VPS 之前，确认虚拟化类型是 KVM，尤其你打算装容器或改网络栈的时候。

**续费会涨价吗？**
Evoxt 香港套餐以月付标价展示，页面上没有“首年 X 折、续费恢复原价”的结构，理论上每月付的就是标价。但官方保留调价权利，长期用的话每隔一段时间核对一次账单。

**能装 Windows 吗？**
可以。官网列出支持从 Windows RDP 到各类 Linux 发行版，Windows 需要自备授权。

**流量用超了会怎样？**
官网条款页有具体说明，本次核验未逐条确认执行方式。做流量敏感的业务，下单前把这条读一遍。
